# Melfis Flowers - Flutter Mobile App

Samarqanddagi Melfis gul do'koni uchun to'liq Flutter mobil ilovasi (Android va iOS).

## Imkoniyatlari:
- 🌸 Barcha saralangan guldastalar va toifalar katalogi
- 🛒 Savatcha va buyurtma berish tizimi
- ⚡ https://melfis.vercel.app bilan to'g'ridan-to'g'ri API integratsiyasi
- 📶 Internet uzilganda maxsus Offline (Internet yo'q) ekrani
- 🎨 Melfis brendiga xos premium dizayn (Krem va to'q yashil)

## Qanday ishga tushiriladi?
```bash
flutter pub get
flutter run
```

## APK chiqarish:
```bash
flutter build apk --release
```
Tayyor APK fayl `build/app/outputs/flutter-apk/app-release.apk` manzilida hosil bo'ladi.
